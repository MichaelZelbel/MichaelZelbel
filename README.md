# Hi, I'm Michael

I build a personal AI that runs on my own machines. It remembers what I tell it, does the
small jobs I keep repeating, and messages me first when something needs me. It is called
Godspeed Mission Control.

**Free:** [Godspeed Mission Control](https://github.com/MichaelZelbel/godspeed-mission-control),
the whole thing in one folder you own. MIT licence.

**The book:** [Teach It Once](https://teachitonce.com) shows you how to build your own, one
small step at a time, whether you can code or not.

**Also here:**

- [awesome-antigravity](https://github.com/MichaelZelbel/awesome-antigravity): a checked list of skills and tools for Google Antigravity.
- [chrome-agent-bridge](https://github.com/MichaelZelbel/chrome-agent-bridge): lets an AI on your server use a real Chrome on your own computer.
- [hermes-self-devops-watchdog](https://github.com/MichaelZelbel/hermes-self-devops-watchdog): Hermes watching Hermes, so your Hermes Agent server stays up.

I write about what I build, and what broke, on [Substack](https://michaelzelbel.substack.com).
